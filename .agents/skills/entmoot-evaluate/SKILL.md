Read [the protocol](../../../evals/PROTOCOL.md) for the claim and oracle, then
the [local recipe](../../../docs/runbooks/revision-evaluation.md#local-history-pilot-and-agent-calibration)
for commands. Reuse history_pilot, agent_trials and pilot_report; keep collection,
product reads, independent answers and reporting separate.

Choose a finite operator question before selecting operations. Git answers exact
file-byte deltas; call-boundary syntax can locate candidate calls. Neither proves
typed dispatch, upgrade safety or a security defect. Failed CI selects candidates
only. Freeze pins, configuration, eligible frame and oracle before model trials;
do not select tasks by Entmoot success or put expected answers into prompts.

Use `agent_trials prepare` to freeze and review inputs without model calls, then
explicit `run` only within the authorized budget. Honor requested pauses at that
boundary; preparation never includes a model availability probe.

Use matched, unchanged CLI/retention binaries and fresh .tmp run directories.
Preserve failed attempts, underfilled strata, source fences and missing counters.
Run the configured small calibration within the user's model/time allowance;
larger trial settings are explicit and do not authorize additional spending.

Grade complete, supported answers. Keep actual input/output usage separate from
delivered-text tokenizer counts; cached/reasoning tokens are subsets. Include
failed attempts and unknown costs, setup separately from warm queries, and both
all-pair and successful-pair results. Regrade stored answers without model calls.
Report repository clusters and calibration limits before updating maturity or
operator guidance. A dated pilot does not qualify later code or a release.
