# entmoot-core

Compiler-free structural inventory, stable identities and source spans using a verified grammar bundle. Grammar sources and upstream licenses are included under `generated/grammars`.

Alpha software: pin the exact prerelease and lockfile; incompatible derivations require rebuilding disposable local publications.

See the [operator guide](https://github.com/tim-gowan/entmoot#readme) and [generated documentation](https://tim-gowan.github.io/entmoot/). Entmoot supplies structural evidence and provenance, not security verdicts or taint analysis.
